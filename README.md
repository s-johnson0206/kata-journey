## 🧠 How I Learn

I'm still figuring out which learning methods work best for me.

One thing I've realized is that understanding code and writing code independently are two different skills.

Being able to follow an explanation doesn't always mean I can immediately recreate the solution on my own.

That's something I'm actively working on.

My learning process generally involves:

1. Reading and understanding the problem.
2. Breaking the problem into smaller pieces.
3. Attempting to solve it using what I already know.
4. Researching or asking questions when I encounter something unfamiliar.
5. Understanding the reasoning behind a working solution.
6. Experimenting with the code to see what changes.
7. Revisiting concepts until they become more familiar.

Sometimes this process takes longer than expected.

I'm learning to focus on genuine understanding rather than rushing through exercises just to finish them.
